# Transformation Logging Review

This folder contains audit outputs generated from `standardized_cleaned_data/transformation_log.csv`.

Current files:

1. `transformation_log_validation_summary.csv`
2. `transformation_log_validation_issues.csv`
3. `transformation_log_dataset_summary.csv`
4. `transformation_log_rule_summary.csv`
5. `transformation_review_queue.csv`

The review checks whether the transformation log can answer the audit questions for each change: original value, new value, rule applied, reason, action type, and review status.
